### 💡 Why this repository exists
Modern AI agents, side-projects, and autonomous systems require reliable LLM inference, but proprietary API costs accumulate rapidly.
This repository runs an **autonomous verification engine** that actively tests each provider daily, confirming that free tiers, free RPM quotas, and developer endpoints remain active, responsive, and ready for production use without sudden billing traps.

## 🤖 How the Autonomous Verification Engine Works
This repository is maintained automatically by a background verification daemon:
1. Every 24 hours, an automated runner sends latency probes and handshake pings to each provider's documentation and dashboard endpoint.
2. Providers that deprecate free tiers or introduce restrictive quotas are flagged and updated.
3. Live badges and latency benchmarks (`ms`) are re-computed and committed directly to `main` via GitHub Actions.
